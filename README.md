# RP-Cloud Labs Tool-Session Service

# Project Overview

RP-Cloud Labs is a platform proposed by Rwanda Polytechnic to provide students and lectures with browser-based access to learning tools without installing then on their personal computers.

# Tool-Session Service

The Tool-Session Service allows students to request access to hosted tools, such as programming environments and database tools. it checks whether a student's account is validated and whether their college has available software license capacity, then records the session.

# Project Purpose

the purpose of this project is to provide a consistent way for students to access learning tools while helping colleges manage their software license capacity.

# Project Scope

This project is focuses on the Tools-Session Service rather than the entire RP-Claud Labs platform.

# Development Team

This project is being developed by group 4 as part of the learner of software engineering module at RP karongi college.
