# Mock Lecturer Interview — RP-Cloud Labs

## 1. Interview Overview

**Project:** RP-Cloud Labs — Tool-Session Service  
**Interviewee:** Lecturer (role-play)  
**Interviewer:** Student requirements analyst  
**Duration:** 5 minutes  
**Purpose:** To identify the lecturer's needs for accessing and assessing students' practical work using the proposed platform.
## 2. Five Needs Identified
## Need 1: Consistent Learning Environment
The lecturer needs students to use the same software environment so that differences between their computers do not affect practical lessons or assessments. This helps students work under similar conditions.
## Need 2: Easy Access to Tools
The lecturer needs students to access hosted software tools through a web browser without installing all the required software on their computers. This saves time and makes practical learning easier.
## Need 3: Reliable Practical Sessions
The lecturer needs students to access practical tools during lessons and assessments without unnecessary interruptions. The system should provide clear messages when a session cannot start.
## Need 4: Fair Assessment
The lecturer needs students to use consistent tools and configurations during practical assessments. This helps ensure that all students are evaluated fairly based on their skills and performance.
## Need 5: Clear Session Availability
The lecturer needs the system to show whether a student can start a session and explain when software licences or other resources are unavailable. This helps students understand access problems.
## 3. Conclusion
The mock interview identified five important needs: consistent software environments, easy access to tools, reliable sessions, fair assessment, and clear information about session availability. These needs will guide the team in defining the functional requirements of the RP-Cloud Labs Tool-Session Service and improving students' practical learning experiences.
